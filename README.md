# o-nosso-repo

## Radar de Mercado · TAM / SAM / SOM

Mini app da JUNITEC para estimar o tamanho de uma oportunidade de mercado ao longo do tempo.

- Escolha de setor, período, regiões geográficas e público-alvo
- Método top-down ou bottom-up
- Cenários pessimista, base e otimista
- Teste de realismo dos pressupostos
- Copiar resultado e exportar CSV

Os valores dos setores, regiões e públicos são **exemplos ilustrativos**, não dados reais. Substituir por fontes reais antes de usar num cliente.

### Publicar
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)`.
A app fica em `https://gdelgado3.github.io/o-nosso-repo/`.
